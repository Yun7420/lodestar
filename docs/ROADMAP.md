## 🎯 다음 스프린트 후보 (우선순위 순)

### A. 게임 자체 개선 (재미가 최우선)

- [ ] **밸런스 튜닝**
  - 30분 이상 실제 플레이 후 광석 HP·스폰 속도·업그레이드 코스트 조정
  - 특히 3분 미스릴 코어가 너무 강하거나 약한지, 5분 이후 다이아·백금 스폰이 감당 안 되는지 확인

- [ ] **커스텀 GA4 이벤트 추가**
  - `gtag('event', 'game_start')`
  - `gtag('event', 'game_over', { time, mined, level, gold })`
  - `gtag('event', 'core_mined', { minute })` (미스릴 처치)

  - `gtag('event', 'level_up', { level, weapon_picked })`

## 🚫 하지 말 것 (User Explicitly Rejected)

- ❌ **Three.js·3D 이식** — 조작감 저해, 코어 루프에 도움 안 됨.
- ❌ **React 도입** — 캔버스 렌더링에 오버헤드. Vanilla JS 유지.
- ❌ **Unity 조기 이식** — 스팀 정식 출시 확정 전까지 안 함. HTML5 유지.
- ❌ **이모지 스프라이트** — 이미 벡터로 전부 대체함.
- ❌ **롱카피·장식적 명명** — "선체 강화" 같은 표현 금지.
- ❌ **완전 채굴 게임 전환** (몹 공격 제거) — 뱀서라이크 코어 유지가 사용자 지침.
